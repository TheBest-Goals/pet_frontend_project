### 2. Для фронтенда (`pet_project_frontend`)
Создай файл `README.md` в корне папки фронтенда и вставь:

```markdown
# 🎨 Roblox Digital Store — Frontend UI

Пользовательский интерфейс для веб-маркетплейса игровoй атрибутики Roblox.

🔗 **Backend репозиторий:** [pet_project](https://github.com/TheBest-Goals/pet_project)

---

## 🛠 Технологический стек

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Styling:** Custom CSS / Responsive Layout

---

## 🚀 Функционал

* 📱 **Каталог товаров:** Отображение карточек робуксов, внутриигровых предметов и наборов.
* 🎯 **Интерактивный UI:** Современный адаптивный дизайн с оформлением под игровой маркетплейс.
* 🔌 **REST API Integration:** Взаимодействие с Java Spring Boot бэкендом для оформления заказов и авторизации.

---

## 💻 Запуск проекта

Просто откройте `index.html` в вашем браузере или запустите через расширение **Live Server** в VS Code.
